## ✨ Key Features & Implementation Highlights

- **🎯 High-Conversion Hero Section:** Clean visual hierarchy with punchy typography, trust badges, and prominent CTA pathways.
- **📱 Fully Responsive Design:** Fluid layouts engineered from mobile (<480px) up to ultra-wide displays (>1440px) using CSS Flexbox and modern CSS Grid.
- **⚡ Vanilla Engineering (Zero Dependencies):** Lightweight, performant execution built with standard modern semantic HTML5, modular CSS3, and ES6+ JavaScript.
- **♿ Accessibility (a11y) Conscious:** High-contrast color palette, logical tab order, clear focus rings, and semantic heading tags adhering to WCAG standards.
- **🎨 Interactive Micro-interactions:** Subtle button hover states, card elevation transitions, and smooth scrolling navigation.

## 🚀 Local Development Setup

To run this landing page locally without build steps or bundlers:

```bash
# 1. Clone the repository
git clone https://github.com/likharlakshya456-boop/assingment.git
cd assingment

# 2. Serve with any static web server (e.g. Python)
python3 -m http.server 3000
```
Open `http://localhost:3000` in your web browser.
