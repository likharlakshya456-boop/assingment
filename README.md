# Due

I made a landing page for Due, a fictional invoice tracker for freelance designers.
Live demo: https://likharlakshya456-boop.github.io/assingment/

## Run locally

I open `index.html` in a browser. No installation or build step is needed.

## Technologies

I used HTML, CSS, and vanilla JavaScript.

## Design choices and challenges

- I used a warm rust accent and light backgrounds to keep the invoice information easy to read.
- I built the invoice list in the hero with HTML and CSS, using sample clients and amounts.
- I used a consistent container width and spacing to align the sections.
- I used CSS Grid to change the columns into a single stack on small screens.
- I added a mobile menu that closes after a navigation link is selected.
- I wrote field-specific form errors and move focus to the first invalid field.
- I made the success message clear that the demo form does not send data.
- I respected reduced-motion settings for smooth scrolling and button transitions.
